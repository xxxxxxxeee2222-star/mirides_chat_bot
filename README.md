# Telegram bot

Run with:

```bash
python bot.py
```

`config.json` must contain:

- `telegram_bot_token`
- `mirides_url`
- `online_url`

If the file is missing in your container, the bot can also read these env vars:

- `TELEGRAM_BOT_TOKEN`
- `MIRIDES_URL`
- `ONLINE_URL`

`chat` aliases:

- `chat`
- `cha`
- `ch`
- `чат`
- `чатик`
